ShortsEngine

ShortsEngine is a personal content automation project by Tejesh Patel. It finds news stories, writes neutral short-form video scripts, renders captioned videos, and sends them through a human review queue before anything is uploaded.

With the owner's permission, ShortsEngine uses the YouTube Data API to upload approved videos to the owner's own YouTube channel. Videos are uploaded as private by default.
